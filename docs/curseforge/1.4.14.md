## 1.4.14

- **Fixed: "Your AddOns are experiencing a large number of errors" in battlegrounds.** Where the game keeps health or an amount to itself, nothing is worked out on it any more (each refused try counted as an error, and a raid's frames piled them up).
- **Players keep their class colour in a fight,** on nameplates and the target frame: in a battleground you can tell a priest from a warrior again.
- **Raid frames show first names,** kept inside their tile, so names no longer run across each other.
