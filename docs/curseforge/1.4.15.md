## 1.4.15

- **Players' names in their class colour, with their class icon,** on nameplates and the target frame, in battlegrounds too: there the game keeps the other side's class to itself, and colours the name and draws the icon for us (`/cchud classnames`).
- **Chat extras off by default:** the class icon and level before names, short channel names and first names only rewrite the game's chat windows, which sets off the game's addon-error warning in battlegrounds and instances. They're switched off once for everyone; each says so if you turn it back on. Spam and recruitment filtering stay.
- `/cchud classprobe` reports what the game allows about your target's class.
