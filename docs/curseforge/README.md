Changelogs written for CurseForge, one file per version (`1.4.0.md`). When a release is uploaded there
(`.github/curseforge_upload.py`), the file for its version is used as the changelog; without one, that version's
part of `CHANGELOG.md` is. Keep them short: what people asked for first, then the rest in a line each, and a link to
the full list. `1.3.0.md` is the one uploaded by hand for 1.3.0.
